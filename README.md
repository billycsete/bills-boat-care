# Build Tasks

Requires Node 20.19+ (run `npm install` first).

| Task              |                                                    |
|-------------------|----------------------------------------------------|
|`npm run dev`      | starts a local dev server with live reload         |
|`npm run build`    | builds to built folder                             |
|`npm run preview`  | serves the built folder locally to preview         |
